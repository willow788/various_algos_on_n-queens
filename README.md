# Various Algorithms on N-Queens

A collection of Python implementations for solving and experimenting with the **N-Queens problem** using breadth-first search, random-state methods, random walks, hill climbing, and combinations of these approaches.

The N-Queens problem asks us to place **N queens on an N×N chessboard** so that no two queens attack each other. In this repository, a board is generally represented as a list where each index represents a row or column and each value represents a queen's position.

> This repository is a work in progress. The programs are primarily experimental implementations and benchmarking scripts.

## Implemented algorithms

| File | Description |
|---|---|
| `Algorithms/bfs_on_n_queens.py` | Breadth-first search that builds valid partial boards row by row. It also measures solution time for several values of `N` and generates a plot. |
| `Algorithms/hill_climbing.py` | Basic hill climbing. It generates neighboring boards by moving a queen and selects the neighbor with the lowest conflict count. |
| `Algorithms/random_walk.py` | Randomly selects a conflicted queen and moves it to a random position until a solution is found or the step limit is reached. |
| `Algorithms/iterative_depth_random_walk.py` | Random walk with an incrementally increased step limit when a solution is not found. |
| `Algorithms/random_State.py` | Repeatedly generates random board states until it finds a solution or reaches the maximum number of attempts. It also includes an average-step experiment. |
| `Algorithms/random_State_mod.py` | Random-state search with a set used to remember previously generated states. |
| `Algorithms/random_state_hill_climbing.py` | Hill climbing with random restarts. A new random state is generated after reaching a local optimum or plateau. |
| `Algorithms/random_Walk_hill_climbing.py` | Combines hill climbing with a random walk when a local optimum is reached. It also benchmarks solution time for multiple values of `N`. |
| `Algorithms/all_combined_hill_climbing.py` | Combines hill climbing, random walks, and random restarts. It includes a configurable restart limit, step limit, and verbose mode, plus a timing experiment. |

## Requirements

- Python 3
- `matplotlib` for the BFS and benchmarking scripts that generate plots

The other algorithm scripts use Python's standard library modules such as `random`, `time`, and `collections`.

Install the plotting dependency with:

```bash
python -m pip install matplotlib
```

## Getting started

Clone the repository and enter its directory:

```bash
git clone https://github.com/willow788/various_algos_on_n-queens.git
cd various_algos_on_n-queens
```

Run an individual algorithm from the repository root. For example:

```bash
python Algorithms/hill_climbing.py
python Algorithms/random_walk.py
python Algorithms/random_state_hill_climbing.py
python Algorithms/bfs_on_n_queens.py
```

Some scripts use fixed values of `N` and benchmark ranges directly in their `main()` functions. To experiment with a different board size, edit the corresponding script before running it.

## Board representation

Most implementations represent a state as a list of length `N`:

```python
[1, 3, 0, 2]
```

Each position describes a queen's location. The algorithms calculate conflicts from shared columns and diagonals, and a solution has a conflict count of zero.

## Notes and limitations

- Basic hill climbing can stop at a local optimum or plateau.
- Random-walk and random-state methods are stochastic, so their output and runtime can differ between executions.
- BFS is complete, but its time and memory requirements grow quickly as `N` increases.
- Several scripts print progress information while running.
- The plotting scripts save generated images to the current working directory unless their output paths are changed.
- The implementations currently have separate helper functions rather than a shared board/state module.
