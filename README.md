# Various Algorithms on N-Queens

This repository contains a collection of Python scripts for solving and studying the N-Queens problem using a range of search and optimization techniques. The implementations are experimental and intentionally varied: some are classic local-search approaches, while others benchmark runtime, visualize performance, or explore alternate heuristic designs.

The goal is not to provide a single polished solver, but to compare different strategies for placing N queens on an N x N board so that no two attack each other.

## What is included

The repo explores several different methods for the N-Queens problem:

- Breadth-first search (BFS)
- Hill climbing
- Random walk
- Random restart methods
- Hybrid local-search strategies
- Genetic algorithms
- Benchmarking and plotting for runtime experiments

## Algorithms in this repo

| File | Description |
|---|---|
| `Algorithms/bfs_on_n_queens.py` | BFS-based search that builds partial board states row by row and benchmarks runtime over several values of N. |
| `Algorithms/hill_climbing.py` | Basic hill climbing using a conflict-count heuristic. |
| `Algorithms/random_walk.py` | Random walk that repeatedly moves a conflicting queen to a random row until a valid solution is found or the limit is reached. |
| `Algorithms/iterative_depth_random_walk.py` | Random walk with an iteratively increasing step budget. |
| `Algorithms/random_State.py` | Random-state generator that repeatedly samples complete board assignments until a solution is found. |
| `Algorithms/random_State_mod.py` | Memory-based random-state search that avoids regenerating states already seen. |
| `Algorithms/random_state_hill_climbing.py` | Hill climbing with random restarts when progress stalls. |
| `Algorithms/random_Walk_hill_climbing.py` | Combines hill climbing with random walk behavior to escape local optima. |
| `Algorithms/adding_sideways_Walk.py` | Sideways-move strategy added to hill climbing to handle plateaus without immediate restart. |
| `Algorithms/all_combined_hill_climbing.py` | Hybrid approach combining hill climbing, random-walk moves, and restarts for experimentation. |
| `Algorithms/genetic_Algo.py` | A genetic algorithm implementation using chromosomes, fitness evaluation, crossover, and mutation. |
| `Algorithms/rewriting_genetic_algo.py` | Alternate rewrite of the genetic-algorithm idea. |
| `Algorithms/jolty_bfs.py` | A variant of BFS with more randomized neighbor generation and restarts. |

## How to run

From the repository root:

```bash
git clone https://github.com/willow788/various_algos_on_n-queens.git
cd various_algos_on_n-queens
```

Run any script directly:

```bash
python Algorithms/hill_climbing.py
python Algorithms/random_walk.py
python Algorithms/random_state_hill_climbing.py
python Algorithms/bfs_on_n_queens.py
python Algorithms/genetic_Algo.py
```

Some scripts are benchmark runners and may generate plots automatically when executed. Others are more focused on the algorithm mechanics or experimentation.

## Board representation

Most of the scripts represent a board as a list of length N, where each index is a column and the value at that index is the row of the queen in that column.

Example:

```python
[1, 3, 0, 2]
```

This means:

- column 0 -> row 1
- column 1 -> row 3
- column 2 -> row 0
- column 3 -> row 2

The algorithms evaluate conflict counts by checking for shared columns and diagonals. A valid solution has zero conflicts.

## Notes

- This project is a learning/experimentation repo rather than a single polished library.
- Many scripts are written to test ideas, compare behaviors, and gather timing data.
- Some algorithms may be stochastic and produce different results across runs.
- Some files include debugging output, benchmark loops, or plotting code directly inside `main()`.

## Summary

This repository is a practical sandbox for exploring how different optimization techniques behave on the N-Queens problem. It is useful for understanding the trade-offs between complete search, local search, stochastic search, and hybrid methods.

If you are learning AI or search algorithms, the scripts in this repo are a good starting point for comparing approaches side by side.
